Edge synthetics are opt-in per tenant again (`enable_edge_synthetics` default `true` → `false`, with the 15 verified-reachable tenants opting in explicitly in `tenants.tf`), removing 56 permanently-alerting tests that #43 created across 8 orgs. #43 retracted the long-standing WAF caveat wholesale on the strength of 16 hand-built UI synthetics that had been running from the public `aws:us-gov-west-1` location since 2026-04 with 15 in `OK`. **Both the original caveat and that retraction were wrong, in opposite directions.** The measured truth is that reachability from `aws:us-gov-west-1` is a **per-tenant** property: `doc doi dot ed fhfa ftc gsa hhs hud ncua opm pc sss stateoig usda` (15) respond normally, while `dnfsb doj faa nrc ntsb oge nsf eeoc` (8) **time out** — `"The request couldn't be completed in a reasonable time"`, with no status code and no TLS error, uniformly across apex *and* console for health, cert and reachability alike. That uniformity plus the total absence of an HTTP response is the signature of a silent perimeter drop, not an app fault; the same endpoints serve `200` with valid certs when probed from inside the allowlist. The retraction's error was generalizing from the passing sample: those 16 tests only ever proved reachability for the hosts they targeted (14 tenants' `chat.` hosts) and said nothing about the 8 tenants that had never had a test, nor about `console.*`. **The laptop trap is the reusable lesson** — #43's pre-apply verification probed all 46 hostnames with `curl` and got `200`/valid-cert for 45 of them, which felt like strong evidence and was worthless: a GSA laptop sits on the network that IS in the WAF allowlist, so it reaches every tenant regardless of what Datadog's egress can do. Laptop `curl` cannot falsify this failure mode, and no amount of it substitutes for one real test run. `var.enable_edge_synthetics` now documents the only valid verification: create one test for the tenant, let it run, and read `/api/v1/synthetics/tests/<id>/results` — or add that tenant's edge to the WAF allowlist for the Datadog gov ranges. `synthetic_locations` keeps its `["aws:us-gov-west-1"]` default since that location demonstrably works for the 15; a private location remains the route to covering the other 8. Net live effect: 105 working tests retained across 15 tenants (including the 14 pre-existing UI tests #43 imported, monitor IDs and alert history intact), 56 destroyed, 0 changed.
